## Purpose

SR 11-7-style outcomes analysis of the exposure model: does a name's channel exposure, computed only from the annual report it had filed before an event, rank-order that event's abnormal returns? Expected sign for every event: negative (higher exposure, lower CAR).

## Design

* **Point-in-time exposure.** For each name and event: the latest original 10-K/20-F with filing date before the event (at most 550 days old) → risk-factor section → `analyze_exposure` → `channel_exposures(...)[channel]`; for the `weaponized` channel the 4W weaponized score / 100.
* **Abnormal returns.** Log returns of adjusted close; market model (OLS α, β) on trading days [-260, -30] (≥ 120 observations) against ACWI; CAR[-1,+5] primary, CAR[-1,+20] secondary.
* **Statistics per event.** Spearman rank IC(exposure, CAR) with t = IC·√((n−2)/(1−IC²)) and two-sided p from Student t(n−2); bootstrap 95% CI (2000 resamples of names, seed 42); Q5−Q1 mean CAR spread (pp, quintiles by exposure rank) with Welch t.
* **Naive baselines** on the same names and CARs: *sector* = mean exposure of the other same-SIC2 names (no peer → mean of all other names); *mention* = raw count of the event's geography in the risk-factor section.
* **Universe.** 40-name coverage universe ∪ KIC Form 13F-HR holdings (period 2026-06-30, filed 2026-08-12) that map to an SEC ticker and file annual reports (644 rows, 641 distinct tickers, 91.3% of 13F value); 646 distinct issuers after de-duplicating share classes. Names without a point-in-time filing, with < 120 estimation days or with an incomplete event window are excluded per event and counted.

## Scope notes

* Point-in-time: each name's exposure comes from its latest original 10-K/20-F filed before the event date (filed at most 550 days earlier); no later filing, price or fundamental enters the exposure.
* Minerals: the channel formula uses the current USGS MCS 2026 country shares (not the edition available at each event date); only the china_export channel uses them (count of relevant minerals with China share >= 50%).
* Company metadata (SIC code for the sector baseline and sector-implied minerals, business-address country for the Taiwan HQ rule) is today's EDGAR submissions record.
* Universe is today's names (coverage universe and the latest KIC 13F), so names that were delisted before today are absent (survivorship).
* Each event is a single cross-section; CARs of names in the same industry are correlated, so the IC t statistic (which assumes independent names) overstates precision. The bootstrap CI resamples names, not dates.
* Event 6 (Red Sea) is tested on the hormuz channel, which is the model's Middle East route channel; the model has no separate Bab el-Mandeb channel.
* Prices: Yahoo Finance chart API adjusted close, log returns; benchmark ACWI (SPY only if ACWI lacks the needed days).
* Issuers that listed through a SPAC are represented before the merger by the SPAC shell's 10-K and trust-value price (same CIK and ticker history), as the declared rules include any name with a point-in-time filing and >= 120 estimation days (e.g. VRT in the 2019 event = GS Acquisition Holdings Corp).
* Whole-document fallback: when the existing parser finds no risk-factor heading it scores the whole annual report (capped at 400k characters); the count per event is reported as risk_section_fallback_n.
* russia_ukraine_2022 → pelosi_taiwan_2022: 109 trading days apart; pelosi_taiwan_2022's estimation window [-260,-30] includes russia_ukraine_2022's primary window days.
* pelosi_taiwan_2022 → bis_advanced_computing_2022: 47 trading days apart; bis_advanced_computing_2022's estimation window [-260,-30] includes pelosi_taiwan_2022's primary window days.
* bis_advanced_computing_2022 → china_gallium_germanium_2023: 183 trading days apart; china_gallium_germanium_2023's estimation window [-260,-30] includes bis_advanced_computing_2022's primary window days.
* china_gallium_germanium_2023 → red_sea_carrier_pause_2023: 116 trading days apart; red_sea_carrier_pause_2023's estimation window [-260,-30] includes china_gallium_germanium_2023's primary window days.
* Sample size: with n names per event, |IC| must exceed roughly 1.65/√(n−2) to reach 10% significance (≈ 0.27 at n = 40, ≈ 0.13 at n = 150).

## Reproduce

```
/usr/bin/python3 etl/build_eventstudy.py            # rebuilds public/snapshots/validation/events.json and this file
/usr/bin/python3 -m pytest -q tests/test_eventstudy.py
```

Inputs are cached under `SENTINEL_CACHE_DIR` (SEC submissions and documents, per-filing exposure JSON, Yahoo price payloads); a rerun with a warm cache makes no SEC document or price requests. Any event's IC can be recomputed from `per_issuer` (Spearman of `exposure` vs `car_pp` over the rows with that `event_id`). Raw prices are not published; `per_issuer` holds only CARs (pp) and exposures.
